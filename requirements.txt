# On-device plate recognition (GATE_LOCAL_OCR_MODE). Both model packages are
# MIT and both ship pure-ONNX weights; onnxruntime supplies the CPU runtime and
# pulls in numpy, and open-image-models pulls in opencv-python-headless for the
# JPEG decode. Pinned to the versions measured on the gate Pi and on the Mac
# (baseline/report.md, baseline/pi_benchmark.md), where reads were
# byte-identical across both machines.
#
# Restricted to arm64 on purpose: the Pi (aarch64) and the development Mac
# (arm64) are the only platforms these graphs were measured on, and keeping
# them off x86-64 means CI installs nothing new and the unit suite continues to
# run with no onnxruntime present - which is exactly how the local recogniser
# must behave when the wheels are missing.
